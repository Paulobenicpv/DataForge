# Preparar o projeto para o GitHub

A distribuição contém código-fonte, configurações, documentação, testes e somente a base fictícia de demonstração.

1. Extraia o ZIP inteiro e abra a pasta raiz que contém pyproject.toml.
2. Execute INICIAR.bat e valide o processamento de data/raw/exemplo.csv.
3. Antes de enviar, confira os arquivos selecionados no Git. A pasta .venv fica no seu computador, excluída pelo .gitignore.
4. Publique os arquivos do projeto, mantendo sua organização de pastas, e confira a renderização do README.

Não inclua bases reais nem pastas de resultados que você criar fora dos caminhos já ignorados. Se usar “Upload files” pelo navegador do GitHub, selecione os arquivos conscientemente: esse mecanismo não aplica o .gitignore como o comando git add.

Nenhuma publicação foi feita automaticamente. O ZIP não inclui histórico Git nem configura uma conta ou um repositório remoto.
